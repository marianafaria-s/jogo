# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I (IFPB - Campus Campina Grande).

## Integrantes
* Seu Nome Completo Aqui

## Como jogar
Digite uma letra no campo indicado e clique em **Tentar** (ou pressione **Enter**). O objetivo é descobrir a palavra secreta antes que as 6 tentativas acabem.

## Tecnologias
* HTML5
* CSS3
* JavaScript

## Funcionalidades
* Escolha aleatória a partir de uma lista de 10 palavras
* Controle de tentativas restantes
* Exibição e bloqueio de letras já utilizadas
* Suporte à tecla Enter para envio rápido
* Reinício de partida a qualquer momento
